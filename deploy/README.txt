Мед. ассистент — запуск
=========================

1. Распакуйте архив В КОРОТКИЙ ПУТЬ, например C:\medassistant
   (глубокие пути ломаются на длинных именах файлов PDF — ограничение
   Windows MAX_PATH).

2. Двойной клик по Start.bat.
   Windows может показать SmartScreen («Windows защитила ваш компьютер»):
   нажмите «Подробнее» → «Выполнить в любом случае». Это обычное
   предупреждение для файлов из интернета, программа ничего не
   устанавливает.

3. Откроется браузер с чатом (http://127.0.0.1:8866). Первый запуск
   грузит модели ~1 мин.

Повторный запуск Start.bat ОСТАНАВЛИВАЕТ всё (переключатель).
Логи: logs\ (llama-answerer/labeler/embed + web, последние 5 запусков).

Требования
----------
- Windows 10/11 x64.
- ~16 ГБ ОЗУ (модели занимают ~7 ГБ в памяти).
- ~10 ГБ свободного места на диске.
- Ничего устанавливать не нужно: python, модели и рекомендации уже внутри.

Видеокарта: дискретная (NVIDIA / Radeon RX / Intel Arc A/B) используется
автоматически; без неё всё работает на процессоре (медленнее).
Если запуск на дискретной карте не идёт — сообщите, есть запасной режим.

Обновление на новую версию
--------------------------
1. Переименуйте СТАРУЮ папку (например, в medassistant_old) — так
   сохранится история чатов (data\sessions.sqlite внутри старой папки;
   при желании перенесите этот файл в новую папку).
2. Распакуйте новый архив В НОВУЮ папку, поверх старой НЕ распаковывать.
3. Запустите Start.bat из новой папки.

Удаление: просто удалите папку. Программа не оставляет следов в системе.
